Tool Definitions

Section 2 of 3 — The 4 MCP tools Velocity exposes. Each maps to existing FastAPI logic.

VELOCITY_USER_ID is resolved from env at startup — never passed by the caller. All tools know who they're serving automatically.
enhance_prompt on demand Transform a raw prompt into a precision-engineered one
prompt* string The raw prompt to enhance
target_ai string? claude · chatgpt · cursor · gemini · bolt · etc.
Returns → annotated card — enhanced prompt, colored technique segments, framework badge, quality score, clarification questions if any
enhance_prompt(prompt="write a function to parse nested json", target_ai="cursor")
refine_prompt on demand Incorporate clarification answers into a tighter refined prompt
original_prompt* string The original raw prompt
clarification_qa* array [{question, answer}] pairs from enhance_prompt output
Returns → refined annotated card — same structure as enhance, with key_additions list showing what changed
refine_prompt(original_prompt="...", clarification_qa=[{question:"...", answer:"..."}])
get_my_context read-only Inspect your Velocity memory graph — persona, domains, recent sessions
(no params) Resolved entirely from VELOCITY_USER_ID
Returns → context summary card — persona label, enhancement count, top domains, frameworks used, recent session summaries, preference tags
get_my_context()
inject_context always-on Returns a system-prompt block the AI prepends to personalize this session
(no params) Resolved entirely from VELOCITY_USER_ID
Returns → plain text block — "User context: expertise=senior, domain=software_engineering, preferred style=concise, recent work: auth system, API design..." Claude prepends this to its own context.
inject_context() // Claude adds result to session context automatically
